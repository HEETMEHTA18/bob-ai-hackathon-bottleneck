# Hackathon Submission Alignment

## Required repository elements from the Bobathon template
The template expects:
- `submission.yaml`
- `README.md`
- `src/`
- `docs/problem-statement.md`
- `docs/solution-overview.md`
- `docs/architecture.md`
- `docs/setup-guide.md`
- demo video link
- live demo URL or `NOT DEPLOYED`
- at least 3 screenshots
- presentation
- `CONTRIBUTING.md`
- `.gitignore`
- unmodified validation workflow

## Evaluation strategy
Technical implementation: 25
Innovation & differentiation: 25
Problem depth & vision: 15
Working demo & functionality: 15
IBM Bob integration: 10
Documentation & reproducibility: 10

## Product mapping
Technical:
- actual ML pipeline
- actual APIs
- actual database
- working dashboard

Innovation:
- risk + impact ranking
- explainable maintenance planning
- crew pre-positioning
- scenario simulation

Problem depth:
- combine telemetry, weather, incidents, and grid impact instead of a standalone failure classifier

Working demo:
- deterministic seeded scenario

Bob integration:
- Bob used throughout architecture/implementation/review
- Bob task-session evidence in `bob_sessions/`

Documentation:
- PRD
- TRD
- MODEL
- CONTEXT
- DATA
- setup guide
- architecture
